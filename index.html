최적화 기준
최적화는 이 화면에서 전투 참여 중인 용만 대상으로 합니다. 탱커·딜러 수는 강제하지 않으며, 전체 팀 누적 피해량을 우선 목표로 둡니다. 결과는 후보 탐색 기반 근사 최적화이며 전역 최적해를 보장하지 않습니다.

인벤토리 · 장비 최적화

보유 젬·장신구·정령·펜던트·물약의 실제 수량과 옵션을 등록합니다. 최적화는 팀 편성 화면에서 전투 참여로 표시된 용만 사용하며, 수량이 한정된 장비는 중복 배정하지 않습니다. 용에게 장착된 장비라도 현재 인벤토리에 등록되어 있지 않거나 보유 수량이 부족하면 후보·기존 추천 비교에서 제외합니다. 비활성 용의 장착분도 현재 인벤토리 옵션·보유량과 대조해 유효한 수량만 재고에서 예약하며, 삭제·수량 초과·옵션 불일치 장비는 최적화 후보와 적용 결과에서 제거합니다. 입력한 데이터는 백업 파일로 따로 보관하세요.

요새 버프 및 전투 보정

요새 버프 설정은 인벤토리 최적화와 같은 화면에서 관리합니다. 값을 바꾸면 이전 최적화 결과는 무효가 되므로 다시 계산하세요. 요새 버프와 전투 설정은 이 브라우저에 자동 저장되어 새로고침해도 유지되고, 팀 프리셋에도 요새 버프가 함께 저장됩니다.

요새 버프

드래곤 목록의 최종 HP·공격력·방어력에 적용하는 계산 설정입니다.

요새 버프 수치는 여기서 직접 입력할 수 있습니다. 자동 버프 최적화 여부는 이중 설정 없이 아래쪽 ‘최적화 범위’에서 선택합니다. 팀 편성 창의 드래곤 카드에서 각 용의 최종 스탯을 확인할 수 있습니다.

확률·속성 보정 (직접 조정 가능)

아군 회피율은 위의 기본 회피율에 드래곤별 장신구·물약 효과를 더해 계산합니다. 중복으로 설정하던 미사용 회피 입력은 제거했습니다.

보스는 속성 보정이 없는 것으로 처리합니다. 아군 방어 확률 25% + 회피 스탯 절반, 보스 회피 약 5%, 보스 방어 기본값 25%, 보스 치명타 기본값 15%는 현재 시뮬레이터의 시작값이며, 실제 게임 확정값으로 검증된 수치는 아닙니다.

✦ 정령 세트

정령 1개를 4개 옵션으로 구성된 한 세트로 등록하고 보유 개수를 입력합니다. ‘귀속 타입’과 ‘귀속 속성’을 지정하면 두 조건을 모두 만족하는 드래곤에게만 배정됩니다. 전체 타입·전체 속성(제한 없음)은 모든 드래곤이 후보가 됩니다. 각 정령 세트의 부가 옵션은 이 목록에서 선택한 값만 사용하며, 보유 목록에 없는 부가 옵션을 최적화 과정에서 만들어 사용하지 않습니다. 다른 부가 옵션을 쓰려면 해당 옵션을 가진 세트를 별도 항목으로 등록하세요. 각 슬롯 수치는 24/28/32/40%, 또는 +54/+60/+66/+120으로 계산됩니다.

정령 상세 화면 스크린샷을 여러 장 고르거나, 여기로 끌어다 놓거나, 붙여넣으세요. 능력치 종류와 %/+ 여부만 읽고 수치는 최고 강화 기준으로 넣습니다. 레벨·강화와 귀속은 읽지 않습니다. 사진은 이 브라우저 안에서만 읽고 전송하거나 저장하지 않습니다.

🔷 펜던트

달의 펜던트는 체력·공격·방어 중 2개 옵션(중복 가능), 태양의 펜던트는 3개 옵션(중복 가능)을 선택하며 옵션 1개당 해당 능력치 +6%입니다. 보유 개수는 실제 펜던트 개체 수로 제한하고, 자동 최적화 시 가능한 조합을 모두 비교해 각 개체의 옵션과 착용 대상을 함께 선택합니다.

체크 시 달의 펜던트 6개 조합(체체·체공·체방·공공·공방·방방)과 태양의 펜던트 10개 조합(체체체·체체공·체체방·체공공·체공방·체방방·공공공·공공방·공방방·방방방)을 모두 검토합니다. 체크 해제 시 달은 공공(+12% 공격), 태양은 공공공(+18% 공격)으로 고정합니다. 기존 사용자 정의 펜던트도 아래 목록에서 계속 사용할 수 있습니다.

보스 패턴 규칙 · P=1 기준

적용 규칙(공용/규칙_현황.md v2.11, 확정 항목 + 사용자가 승인한 유력 항목): ① 3의 배수 관통 후속 앞열 분배는 앞열 생존 수와 무관하게 P=1.0(B5) ② 일반 단일 공격은 열(앞·뒤 짝) 하나를 고르고, 그 열의 앞이 전투불능이면 같은 열의 뒷열을 공격(B2, P=1.0). ④ 단일과 관통의 열 선택(B8 유력, v2.10): 앞 생존 열(슬롯 순) + 앞 사망·뒤 생존 열(슬롯 순)의 앞 6개, 순위별 가중치 45·20·15·10·5·5. ③ 아군 방어 확률은 기본 회피율을 뺀 화면 추가회피로 계산(C2 유력, 사용자 승인: 25% + 추가회피/2). 일반 턴 앞열 분배 min(10/N,2)·관통 앞 1.5·전체 0.5. miss = 기본 회피 5% + 추가회피. ⑤ 관통 뒷열(B4, v2.11): 고른 열의 앞 생존 0.5 / 앞 사망·앞열 잔존 1.5(유력) / 앞열 전멸 1.0(가설), 약화 충족 팀에만 적용. 후반 보스 치명 상승과 관통 뒷열 반례(앞 생존인데 1.5, 약 4%)는 반영하지 않음.

3의 배수 · 관통 + 관통 후속 앞열전체

열 하나의 앞·뒤를 관통한 뒤, 생존 앞열 전원을 공격(앞열 전멸이면 뒷열 전원)

축복 + 전투 참여 공격형 5마리 이상: 관통 앞 P=1.5 / 관통 뒤 P=0.5 · 그 열의 앞이 전투불능이면 뒤 1.5 · 앞열 전멸이면 뒤 1.0 (B4)
조건 미충족: 관통 앞 P=3.0 / 뒤 P=1.5 · 그 열의 앞이 전투불능이거나 앞열 전멸이면 뒤 3.0 (관측 사례 없음)
관통 후속 앞열전체: 생존 수와 무관하게 P=1.0
관통 열 선택: 아래 '열 선택' 규칙
그 외 · 일반 공격

단일 공격 또는 앞열전체 공격(각 50%)

앞열전체: P=min(10/N, 2), N = 맞는 열의 생존 수(앞열 전멸이면 뒷열)
단일: P=1.0 · '열 선택' 규칙으로 열 하나를 고르고 앞이 전투불능이면 같은 열의 뒤를 공격
강한 단일 공격 옵션은 단일 공격이 선택된 경우에만 적용

강한 단일 공격은 판독에서 관측되지 않은 가정용 옵션입니다(기본 꺼짐). 켜면 단일 공격이 선택될 때 지정 확률로 P=1.5(축복 + 공격형 5마리 이상) 또는 P=3.0(그 외)이 됩니다.

열 선택 · 관통 공격 대상 비중

단일과 관통이 같은 방식입니다. 앞 생존 열(슬롯 순) + 앞 사망·뒤 생존 열(슬롯 순)의 앞 6개를 후보로, 순위별 가중치 45·20·15·10·5·5로 고릅니다(공용 B8, v2.10).

현재 적용 확률을 계산하는 중입니다.
배율 해석 및 전투 순서
P=1.0을 기준 공격으로 표시합니다. P=1.5는 기준 공격의 1.5배, P=0.5는 절반입니다. 30회처럼 3·10의 공배수에서는 전체 공격 + 관통 + 앞열 분배가 모두 실행됩니다.
전투 순서(확정): 뒷열 슬롯 11→20 선공 → 보스 → 앞열 슬롯 1→10 → 보스 → 뒷열 … 반복. 원래 앞열 1~10번이 전멸하면 생존 뒷열이 보스의 앞열 판정 대상이 되고, 보스 공격마다 공격합니다.
정확성 안내: 보스→아군 피해 공식·공격 배율·회피/방어 확률과 아군→보스 피해 공식·행동 순서는 실제 전투 영상 판독으로 검증했습니다(공용/규칙_현황.md). 세팅1(8전투)과 억까(3전투)의 평균 누적 피해·처치 확률이 시뮬레이터와 오차 범위 안에서 맞습니다. 관통 뒷열 조건(B4, 유력·가설), 열 선택 가중치(유력), 축복 약화 조건을 충족하지 않는 팀의 배율(미관측)은 아직 확정이 아닙니다. 타입별 기본 스탯과 장비 수치, 스탯 누적·버림 순서는 이전 시뮬레이터의 모델을 이어받았습니다. 게임 결과와 다르면 해당 입력값이나 규칙을 수정해야 합니다.

회귀 테스트

코드를 고친 뒤 핵심 규칙이 그대로인지 확인합니다. 피해 공식(판독값), 보스 규칙, 앞열 전멸·열 단위 단일, 세팅1 실제 전투(8전투 평균 70,812)와의 비교, 두 전투 엔진의 일치, 캐시 키를 검사합니다. 규칙·엔진 테스트는 화면 입력과 무관한 고정 설정으로 돌리고, 캐시 키 테스트는 입력을 잠시 바꿨다가 되돌립니다. 편성과 인벤토리는 바꾸지 않습니다. 약 3~5초 걸립니다.

인벤토리·추천 적용 테스트는 사양서 34절 6~13번(재고 초과, 과거 장착 복원, 후보 독립성, 중간·최종 구분, 추천 적용, 적용 후 스탯, 실행 중 인벤토리 변경)을 테스트용 팀·인벤토리로 실제 최적화를 돌려 검사합니다. 끝나면 편성·인벤토리·추천 결과·설정을 원래대로 되돌리고, 도중에 창이 닫혀도 다음에 열 때 저장된 인벤토리를 복구합니다.

1군 → 2군 이어서 전투

1군이 전멸하면 2군이 남은 보스 HP와 이어지는 턴 번호로 싸웁니다. 각 구간은 그 부대의 보스 조건(1군: 1군 설정, 2군: 축복 미적용 등 2군 설정)을 쓰고, 2군은 들어오자마자 뒷열이 먼저 공격한다고 가정합니다. 반복 횟수와 시드는 위의 값을 씁니다. 1군과 2군 편성은 상단 1군·2군 화면의 현재 편성입니다.

⑤ 정령 고점 · 가능한 정령 조합 전체 탐색

정령 고점은 실제 보유 여부와 관계없이 생성 가능한 정령의 4개 메인 옵션과 부가 옵션을 탐색해 각 드래곤에 가장 적합한 조합을 찾습니다. 선택한 정령은 가상 추천이며, 실제 인벤토리에 정령을 추가하거나 보유 수량을 차감하지 않습니다. 젬·장신구·펜던트·물약은 실제 보유 수량 안에서 함께 배정합니다.

정령 고점과 인벤토리 최적화의 차이
정령 고점: 보유하지 않은 정령도 후보로 생성하며, 드래곤별 생존·누적 피해를 기준으로 정령 조합을 고릅니다. 인벤토리 최적화: 실제 보유 정령과 귀속·수량 제한을 지켜 팀 전체 장비 배분을 찾습니다. 정령 고점 결과를 팀에 적용하면 가상 정령 옵션은 드래곤 설정에 기록되며, 인벤토리 정령 재고는 변경되지 않습니다.
